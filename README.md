# 夜市叠叠高 · Night Market Stack

一个用原生 JavaScript 与 Canvas 2D 编写的夜市主题叠叠乐。点击或触摸屏幕让小吃落下，叠得越高分越高，对齐得足够准会触发 PERFECT 连击。

当前版本：`v0.4.1`

## 本地运行

项目每天更新一个可玩版本，根目录始终是最新版。

因为页面会加载同目录的 `logic.js`，建议通过本地 HTTP 服务启动：

```powershell
python -m http.server 8765
```

在项目根目录运行上面的命令，然后打开 [http://localhost:8765/](http://localhost:8765/)。

也可以用任意静态文件服务器启动。游戏运行本身没有第三方依赖。

## 操作

- 点击开始按钮进入游戏。
- 点击或触摸屏幕任意位置，让当前小吃落下。
- 小吃和下方一层重叠得越多，留下的宽度越大。
- 中心偏差不超过 12px 为 PERFECT，连续 PERFECT 会提高得分。
- 重叠不足 10px 时游戏结束，可以立即重开。
- 右上角按钮控制声音，静音状态会保存在浏览器本地。
- 最高分也会保存在浏览器本地。

## 技术栈

- HTML、CSS、原生 JavaScript
- Canvas 2D
- WebAudio 程序化合成音效
- `localStorage`
- Node.js 逻辑测试

判定和计分位于 [`logic.js`](logic.js)。它使用 UMD 包装，同一份代码既能被浏览器加载，也能被 Node.js 直接测试。

## 运行测试

```powershell
node tests/smoke.test.js
```

测试覆盖重叠计算、PERFECT 边界、普通判定、失败阈值、连击计分和重开初始状态。任何一项失败时，命令会返回非零退出码。

## 当前能力与限制

- 已有完整核心循环、手感反馈、四类合成音效、移动端安全区适配，以及木托盘小吃、多层夜景、星空月晕和串灯组成的原创夜市美术。
- 固定种子 20 局的自动测试平均为 30.75 次点击，最短 27、最长 38。
- 自动浏览器检查已覆盖开始、计分、失败、重开、音效和静音。
- 真实手机 5 局的主观触控、刘海区域、音量和震屏验收仍待完成。
- 目前没有排行榜、账号、分享、皮肤或正式 E2E 测试套件。
